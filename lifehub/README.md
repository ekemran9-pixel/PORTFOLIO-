# LifeHub: আপনার ব্যক্তিগত অটোমেশন হাব (Phase 1)

শুধু আপনার জন্য একটা private dashboard। কাস্টমার লিস্ট, আয়-ব্যয় আর কাজের এন্ট্রি, ছবি/ভিডিও/নোট এক জায়গায় থাকবে, সাথে Excel ইমপোর্ট/এক্সপোর্ট। বাংলা ও English দুই ভাষাতেই চলে, মোবাইলে অ্যাপের মতো ইনস্টল করা যায়।

## যা আছে (Phase 1)

| পেজ | কাজ |
|---|---|
| ড্যাশবোর্ড | এ মাসের আয়/ব্যয়/ব্যালান্স, ৬ মাসের চার্ট, বাকি কাজ, নতুন কাস্টমার, সাম্প্রতিক ছবি, কার্যক্রম |
| কাস্টমার | যোগ/এডিট/মুছুন, সার্চ, ট্যাগ, প্রত্যেকের আলাদা প্রোফাইল (কল, WhatsApp, তার এন্ট্রি ও ফাইল) |
| ডেটা এন্ট্রি | আয়, ব্যয়, কাজ, নোট; তারিখ/ধরন/অবস্থা দিয়ে ফিল্টার, এক ক্লিকে কাজ সম্পন্ন |
| মিডিয়া ভল্ট | ছবি, ভিডিও, অডিও, PDF/Word/Excel আপলোড (ড্র্যাগ-ড্রপ, মোবাইল ক্যামেরা), টেক্সট নোট |
| Excel ইমপোর্ট | .xlsx / .xls / .csv; কলাম নিজে থেকে মিলে যায় (বাংলা হেডারও চেনে) |
| এক্সপোর্ট | CSV ও Excel (.xlsx), ফিল্টার সহ |
| সেটিংস | API key রাখার জায়গা (Gemini, Groq, OpenAI, Claude, Notion, Telegram), পাসওয়ার্ড বদল, ব্যাকআপ |

**নিরাপত্তা:** লগইন ছাড়া কিছুই দেখা যায় না, ফাইলগুলোও না। ৫ বার ভুল পাসওয়ার্ড দিলে লগইন ১৫ মিনিট বন্ধ থাকে। সব ফর্মে CSRF সুরক্ষা আছে, আর API key শুধু সার্ভারেই থাকে।

## cPanel-এ চালু করার নিয়ম (১৫ মিনিট)

### ১. ডেটাবেস বানান
1. cPanel → **MySQL® Databases**
2. **Create New Database**: যেমন `lifehub` (cPanel নিজে থেকে নাম দেবে `cpuser_lifehub`)
3. **Add New User**: ইউজার আর একটা শক্ত পাসওয়ার্ড দিন, লিখে রাখুন
4. **Add User To Database** → **ALL PRIVILEGES** → Make Changes

### ২. ফাইল আপলোড করুন
1. cPanel → **File Manager** → `public_html` (অথবা সাব-ডোমেইনের ফোল্ডার, যেমন `public_html/hub`)
2. **Upload** → `lifehub.zip` আপলোড করুন → ফাইলের উপর রাইট-ক্লিক করে **Extract** দিন
3. `lifehub` ফোল্ডারের ভেতরের সব ফাইল যেখানে সাইট চালাতে চান সেখানে রাখুন। **Settings → Show Hidden Files** চালু করে নিন, যাতে `.htaccess` ফাইলগুলোও দেখা যায় এবং সাথে যায়।

### ৩. PHP ভার্সন
cPanel → **Select PHP Version** (বা MultiPHP Manager) থেকে **PHP 8.1 বা নতুন** বাছাই করুন। `pdo_mysql`, `fileinfo` আর `mbstring` extension চালু রাখুন।

### ৪. ইনস্টল
1. ব্রাউজারে খুলুন `https://আপনার-ডোমেইন/install.php`
2. ডেটাবেসের নাম, ইউজার আর পাসওয়ার্ড দিন, তারপর নিজের অ্যাডমিন ইউজারনেম ও পাসওয়ার্ড দিন → **Install**
3. ✅ এরপর File Manager থেকে **`install.php` ডিলিট করুন**

### ৫. HTTPS (জরুরি)
cPanel → **SSL/TLS Status** → **Run AutoSSL** (ফ্রি)। এরপর `.htaccess`-এ “Force HTTPS” অংশের তিনটি লাইনের সামনের `#` মুছে দিন।

### ৬. মোবাইলে অ্যাপের মতো চালান
ফোনের Chrome-এ সাইট খুলে মেনু (⋮) → **Add to Home screen**।

## বড় ভিডিও আপলোড
প্রতি ফাইলে ডিফল্ট সীমা ২০০MB (`.user.ini`-তে লেখা আছে)। আপনার হোস্টিং কম দিলে cPanel → **Select PHP Version → Options** থেকে `upload_max_filesize` আর `post_max_size` বাড়িয়ে নিন।

## ব্যাকআপ
- **ডেটা:** সেটিংস → ব্যাকআপ ডাউনলোড (JSON)। অথবা cPanel → phpMyAdmin → Export
- **ফাইল:** `uploads/` ফোল্ডারটি zip করে ডাউনলোড করে রাখুন

## ফোল্ডার গঠন
```
index.php        ড্যাশবোর্ড
customers.php    কাস্টমার লিস্ট / ফর্ম      customer.php  প্রোফাইল
entries.php      ডেটা এন্ট্রি
media.php        মিডিয়া ভল্ট               file.php      সুরক্ষিত ফাইল দেখানো
import.php       Excel ইমপোর্ট               export.php    CSV / Excel এক্সপোর্ট
settings.php     API key, পাসওয়ার্ড, ব্যাকআপ
inc/             মূল কোড (ব্রাউজার থেকে বন্ধ)
lang/bn.php      বাংলা লেখা — শব্দ বদলাতে চাইলে এখানে
lang/en.php      English লেখা
assets/          ডিজাইন (app.css), জাভাস্ক্রিপ্ট, আইকন
uploads/         আপলোড করা ফাইল (ব্রাউজার থেকে সরাসরি বন্ধ)
```
