📱 ফোন অ্যাপ ও Webhook API

iPhone Shortcuts, Android MacroDroid/Tasker, n8n, Zapier, IFTTT বা Make থেকে এই URL-এ পাঠালে LifeHub কাজ করবে।

উদাহরণ ও নিয়ম

iPhone Shortcuts / Android MacroDroid: “Get Contents of URL” / “HTTP Request” অ্যাকশন বানান, Method = POST, Header-এ Authorization দিন, Body = JSON। “Dictate text”-এর সাথে মিলিয়ে কথা বলে হিসাব যোগ করা যায়, উত্তর “Speak text” দিয়ে শোনা যায়।

POST https://lifehub-demo.netlify.app/hook.php
Authorization: Bearer fa8055…
Content-Type: application/json

{"action":"say","text":"আজ ৫০০ টাকা যাতায়াত খরচ"}
{"action":"add_entry","type":"income","title":"Sale","amount":2500}
{"action":"add_customer","name":"Karim","phone":"017…"}
{"action":"report","period":"today"}
{"action":"run_recipe","id":1}

n8n / Zapier / Make / IFTTT: Webhook/HTTP অ্যাকশনে একই URL ও token ব্যবহার করুন। উল্টো দিকে পাঠাতে রেসিপির “Webhook পাঠাও” অ্যাকশন ব্যবহার করুন।
