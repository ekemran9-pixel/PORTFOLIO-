📱 Phone apps & webhook API

Send requests to this URL from iPhone Shortcuts, Android MacroDroid/Tasker, n8n, Zapier, IFTTT or Make and LifeHub acts on them.

Examples & rules

iPhone Shortcuts / Android MacroDroid: Create a “Get Contents of URL” / “HTTP Request” action, Method = POST, add the Authorization header, Body = JSON. Combine with “Dictate text” to log by voice and “Speak text” to hear the answer.

POST https://lifehub-demo.netlify.app/hook.php
Authorization: Bearer fa8055…
Content-Type: application/json

{"action":"say","text":"আজ ৫০০ টাকা যাতায়াত খরচ"}
{"action":"add_entry","type":"income","title":"Sale","amount":2500}
{"action":"add_customer","name":"Karim","phone":"017…"}
{"action":"report","period":"today"}
{"action":"run_recipe","id":1}

n8n / Zapier / Make / IFTTT: Use the same URL and token in a Webhook/HTTP action. To send data the other way use a recipe with “Send a webhook”.
